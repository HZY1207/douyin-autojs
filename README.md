# 抖音极速版自动刷视频脚本（AutoJs6）

基于 **AutoJs6** 的安卓自动化脚本：通过截图实时识别抖音极速版右上角「红包挂件」的主体颜色——**金色表示红包还在计时，继续观看并自动点赞；红色表示计时结束，立即上滑切下一个视频**。无需 root，仅使用截图权限 + 无障碍手势。

## 工作原理

1. 进入视频后，按归一化坐标截取红包挂件主体区域（已用 864×1920 与 1080×2400 两张全屏截图交叉标定，换分辨率自动适配）。
2. 对采样区逐像素做 HSV 颜色分类（排除奶油色进度环、中央圆钮和深色背景）：
   - 红色色相 `H ≤ 30° 或 H ≥ 322°` → **RED**
   - 金色色相 `30° < H < 70°` → **GOLD**
3. 连续 2 次判定一致才动作，防止转场动画造成误滑：
   - **GOLD** → 继续观看，首次判定金色时双击屏幕点一个赞（不关注、不评论）
   - **RED** → 立即上滑切下一个视频
   - **无挂件** → 宽限 8 秒后按正常看完处理，避免新视频连滑
   - 一直金色不变色 → 60 秒超时兜底滑走

## 功能特性

- 纯像素判色，不依赖控件 ID，抖音改版后可用标定模式快速重新定位
- 归一化采样区 + 自动搜索兜底（连通域识别右上角色块）
- 音量上键随时停止，结束输出统计（视频数 / 红 / 金色超时 / 无挂件 / 点赞数 / 用时）
- 前台守卫：息屏或切到其他 App 时自动暂停，**不会在别的界面乱滑**
- 随机滑动时长与间隔、连续 6 个秒滑后自动停顿 4 秒，降低机械操作特征
- 低配机模式（`PERF_LOW`）：每次判定只截 1 帧，骁龙 6xx 实测红色视频约 3 秒滑走
- 严格 ES5 写法（仅 `var`、无箭头函数 / 模板字符串 / 类型化数组），兼容 AutoJs6 的 Rhino 引擎

## 运行环境

| 项 | 要求 |
| --- | --- |
| App | AutoJs6（建议 6.x，支持 `captureScreen` / `Image.pixel`） |
| 权限 | 截图（录屏）权限、无障碍服务 |
| Root | 不需要 |
| 测试机型 | OPPO A72 / Android 10 / ColorOS，1080×2400 |

## 使用方法

1. 将 `douyin_lite_auto.js` 传到手机，用 AutoJs6 打开。
2. 开启 AutoJs6 的**无障碍服务**，运行脚本并允许**截图权限**。
3. 打开抖音极速版，进入红包挂件可见的视频流，脚本自动开始。
4. 按**音量上键**停止。

> ColorOS 等国产 ROM 需在系统设置中允许 AutoJs6 自启动、后台运行，并在最近任务里给应用加锁，否则可能被系统杀后台，详见 [PROMPT.md](PROMPT.md) 第 12 节。

## 标定模式（换机 / 抖音改版后）

把脚本顶部改为：

```js
var MODE = "calibrate";
```

运行后会保存一张全屏截图、自动搜索红包挂件并打印可直接填入 `CFG.BODY_NORM` 的归一化坐标与该区域颜色统计。

## 关键参数

脚本顶部 `CFG` 对象可调整：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `MAX_WATCH_MS` | 60000 | 金色视频最长停留，超时兜底滑走 |
| `STABLE_HITS` | 2 | 连续几次判定一致才动作（不建议改为 1） |
| `POLL_MS` | 250 | 判色轮询间隔（ms） |
| `PERF_LOW` | true | 低配机模式：单帧采样 + 跨轮次去抖 |
| `LIKE_ON_GOLD` | true | 金色红包视频是否自动点赞 |
| `MAX_VIDEOS` / `MAX_MINUTES` | 0 / 0 | 限个数 / 限时长停止，0 = 无限 |
| `BODY_NORM` | 已标定 | 红包主体归一化采样区 |

## 本地测试（无需手机）

`_analysis/` 提供 PC 端模拟器，用真实截图像素驱动真脚本，5 个场景共 23 项断言：

```bash
node _analysis/run_mock.js
```

覆盖：金色→点赞并继续看、红色→滑走、一直金色→60 秒兜底、一进就红→约 3 秒秒滑、不在前台→暂停不乱滑、标定模式。

另附两个静态体检脚本：

```bash
python _analysis/check_es5.py       # Rhino / ES5 兼容性
python _analysis/lint_cfg_keys.py   # 检查漏写 CFG. 前缀
```
